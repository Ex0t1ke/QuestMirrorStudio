Полноценная программа с современным графическим интерфейсом для трансляции изображения со шлемов **Meta Quest 3S / 3 / 2** на экран ПК или ноутбука с ультранизкой задержкой (15–25 мс) в **60, 72, 90 или 120 FPS**.

Не требует установки официального софта Meta Horizon Link, не требует интернета и не зависит от серверов Meta!

## ✨ Возможности

* 🚀 **Чистые 60–120 FPS:** использует аппаратный декодер вашей видеокарты (NVIDIA NVDEC / AMD / Intel) для нулевой задержки.
* 👁 **Идеальное кадрирование 16:9:** вырезает правый или левый глаз под стандартные мониторы и летсплеи (без черных круглых рамок и рыбьего глаза).
* 🔊 **Параллельный звук (`audio-dup`):** звук из VR-игр одновременно играет в динамиках шлема и передается в динамики ПК.
* 📶 **Беспроводной Wi-Fi режим в 1 клик:** подключите кабель, нажмите «Включить Wi-Fi режим», и кабель можно отсоединять.
* 🔋 **Мониторинг:** уровень заряда батареи шлема и тип подключения отображаются прямо в окне программы.
* 🎥 **Запись видео:** кнопка автоматической записи геймплея в `.mp4` файл.
* ⚡ **Энергосбережение шлема:** горячая клавиша `Alt + O` выключает дисплей шлема во время стрима (шлем работает в 3 раза дольше).

## 🚀 Быстрый старт

### 1. Подготовка шлема (1 раз)
1. В мобильном приложении **Meta Horizon** на смартфоне перейдите в:  
   `Меню` → `Устройства` (ваш Quest) → `Настройки гарнитуры` → `Режим разработчика` → переведите в **ВКЛ**.  
   *(Если шлем просит создать организацию, откройте [developer.oculus.com](https://developer.oculus.com) и введите любое название, это бесплатно)*.
2. Подключите Quest кабелем Type-C к компьютеру.
3. Наденьте шлем и в появившемся окне поставьте галочку **«Всегда разрешать с этого компьютера»** и нажмите **«Разрешить»**.

### 2. Запуск
1. Запустите скачанный **`QuestMirrorStudio.exe`**.
2. Убедитесь, что индикатор загорелся зеленым: `● Meta Quest 3S готов к трансляции`.
3. Нажмите **«▶ ЗАПУСК ТРАНСЛЯЦИИ»**.

## 🎮 Горячие клавиши окна трансляции

| Сочетание | Описание |
| :--- | :--- |
| **F11** или **Alt + F** | Полный экран (Fullscreen) / Оконный режим |
| **Alt + W** | Убрать черные рамки по краям |
| **Alt + O** | **Выключить дисплей шлема** (картинка на ПК идет, батарея шлема экономится!) |
| **Alt + Shift + O** | Включить дисплей шлема обратно |
| **Alt + I** | Включить/выключить счетчик FPS |
| **Alt + Q** | Закрыть окно трансляции |

## 🛠 Сборка из исходников (для разработчиков)

Если вы хотите запустить проект из исходного кода Python:

```bash
git clone https://github.com/Ex0t1ke/QuestMirrorStudio.git
cd QuestMirrorStudio
pip install -r requirements.txt
python app.py
```

Для сборки автономного `.exe` файла:
```bash
pyinstaller --noconfirm --onefile --windowed --name "QuestMirrorStudio" --icon "app.ico" --add-data "bin;bin" --collect-all customtkinter app.py
```
